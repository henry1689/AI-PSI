## 4. 运行层级结论

- Session 定义：用户或调用方与系统之间的一段**逻辑交互上下文**；**不自动拥有**世界模型、观点、记忆或完整认知状态
- Task 定义：具有明确目标、边界、生命周期和结果状态的**工作单元**；可以跨多个 Turn
- Turn 定义：一次输入接收至该次响应或明确终止结果之间的**交互边界**；可以触发一个或多个 Cognitive Run
- Cognitive Run 定义：为某个 Task 或 Turn 执行的一次**受控认知运行实例**；**必须有稳定执行身份**
- Cognitive Cycle 定义：运行中的一次**状态读取—候选生成—校验—提交或继续**决策回路
- Cognitive Step 定义：认知循环中的**最小可调度逻辑步骤**；**不因被调度而获得权威写权限**
- Model Call 与 Turn 的关系：**Model Call 不是 Turn，也不是 Cognitive Cycle**；模型输出是候选内容，可失败、超时、重试或被替代，**重试后的输出不保证逐字一致**
- Tool Call 与认知提交的关系：**Tool Call 不等于认知提交**；工具执行成功 ≠ 认知提交成功 ≠ 外部副作用成功；工具结果是**不可信输入**

**层级规则要点**：Task 完成**不能仅由模型自由文本声明**，必须由生命周期组件按结构化结果提交；**`NO_CHANGE` 是合法结果**；不能只用最大模型调用次数作为唯一终止条件。

## 7. 并发、重试与副作用

- 并发控制原则：**乐观并发或等价版本校验**；**提交必须携带预期前序版本**；**版本冲突不得静默覆盖**
- 模型调用重试原则：**产生新的 Attempt ID**，**必须与原始逻辑调用关联**；重试可能产生不同候选，新候选须重新走校验
- 工具调用重试原则：**必须服从副作用分类**（只读/计算/幂等写可重试；非幂等与高风险**禁止自动重试**）
- 非幂等副作用处理：**禁止自动重试**；超时后进入 `INDETERMINATE`；**补偿操作必须被视为新操作，而非删除历史**
- 工具超时语义：**超时不表示工具一定未执行**；结果未知时**不得**伪造成功或失败
- 幂等键语义：用于**重复请求去重**；**不能代替业务对象身份**；**新业务意图必须使用新幂等身份**
- 部分提交处理：**必须形成显式恢复状态**；多个权威系统的提交**不得伪装为单一原子事务**；多提交时须定义顺序、补偿与可恢复状态
- `INDETERMINATE` 使用条件：无法确认外部副作用结果、提交结果无法判定时；**不得伪装为失败或成功**，须产生告警或治理信号并进入人工/结构化协调
