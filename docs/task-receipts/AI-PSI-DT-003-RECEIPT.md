## 4. 核心概念结论

- 世界模型定义：主体用于组织实体、关系、事件、状态、主张及其时间和来源关系的**可修订内部表示**；**不等于**外部现实本身、不可修改的事实集合、LLM 参数、长期记忆或主体当前观点
- Claim 是否等于事实：**否**。主张是可被支持、反驳、限定、撤回或暂缓判断的命题性表达，**不因被写入世界模型就成为客观事实、已接受信念或正式观点**
- Belief 定义：主体对某主张所持的、具有范围、依据、不确定性和生命周期的**认识性承诺**；**不得**定义为"模型曾生成过的文本"
- Opinion 定义：主体针对某问题、主题或决策对象形成的**综合立场**，可综合多个信念、证据状态、价值约束、目标与上下文、不确定性和竞争解释
- Current Subject Viewpoint 定义：**观点系统正式提交**的、主体在特定观点键、范围与上下文下当前采用的正式立场；可明确为 `UNDETERMINED` / `DEFERRED`
- Opinion 与 Belief 的关系：**已形成明确结论**——Belief 偏向对**命题真值/可信程度**的认识性承诺；Opinion 偏向对**问题或主题**的综合立场；**多对多引用**；Opinion 可含规范性、偏好性或决策性成分，Belief 不应承载未说明的偏好；**逻辑语义必须分离**，物理存储可共享基础设施（第二篇 2.7）
- Unknown、Undetermined、Negative 是否分离：**是**。并进一步区分"未建立 / 信息不足 / 竞争未统合 / 明确暂缓 / 已撤回"五种"没有观点"的状态，**不得用同一个空值掩盖**
