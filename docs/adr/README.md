# 架构决策记录（ADR）

本目录记录 AI-PSI Cognitive Runtime 的架构决策。
每条 ADR 保留**决策当时**的背景、替代方案与影响——
目的是让后来者能理解"为什么是这样"，而不只是"是什么"。

**格式**：状态 / 日期 / 相关 → 背景 → 决策 → 替代方案与取舍 → 影响

**规则**：
- ADR 一旦接受，**不修改内容**。要改变决策就新增一条 ADR 并标注取代关系。
- 任务书自身的矛盾与缺口的处理，同样记录为 ADR（不就地改任务书）。

### 阶段 7 新发现的缺口（见 ADR-0024）

| # | 缺口 | 处理 |
|---|---|---|
| G31 | 🔴 **`_covered_keys()` 被当成了并发防线，而它只是一次读**。ADR-0023 §6 把"重试不得重复创建 Proposal"推给提案层，那句话在**顺序**重试下成立，在**并发**下是空的——两个运行各自读到"还没有提案"的旧快照 | 唯一性交给 PostgreSQL：部分唯一索引 `uq_improvement_proposals_active_pattern`；`_covered_keys()` 降级为快速路径（ADR-0024 §2） |
| G32 | 🔴 **`(error_class, applicability)` 与 `_covered_keys` 的键不等价**——空数组在整数组唯一下会相撞（而应用层认为它们不覆盖任何东西），多元素数组在整数组下是两个键（而应用层按 `[0]` 认为是同一个） | 索引表达式写 `(applicability[1])`，与应用层逐字同构；部分谓词排除空 applicability（ADR-0024 §2.1–2.2） |
| G33 | 第一次建索引时可能撞上**历史竞态留下的重复行**（实测：跑红一次就留下 `(evidence_error, d2\|no_evidence\|h2) × 2`） | 迁移先诊断、报错并逐条列出冲突，然后中止；**不自动清理**——提案是审计记录（ADR-0024 §5） |

| # | 缺口 | 处理 |
|---|---|---|
| G18 | §11.3 的"三次同类错误"没有定义**计数单位**，而 `Experience.error_type` 同时表达"怀疑"与"确认" | 拆成四档评价 + 权重（ADR-0020 §1）；门槛定义写入 ADR-0020 §3 |
| G19 | 经验没有**规范身份**，同一回合重复抽取可冒充独立经验 | `canonical_key` + `independence_group`（ADR-0020 §2），**两个派生值各有一条逐字核对的模型校验器**；⚠️ 曾在此登记的 "PostgreSQL 部分唯一索引" **从未建立**，已降级为设计意向并写明理由（ADR-0020 §2、风险 R60） |
| G20 | §11.4/§12.2 的反馈路径在单事务与"不丢用户的话"之间**没有说明取舍** | 改单事务，代价与承接机制显式写入 ADR-0021 §1 |
| G21 | 空白判据两层各写一份，且都放行零宽字符 | 收敛到 `domain/common.is_blank`（ADR-0021 §2） |

| G25 | §12.4 不存在创建提案的接口，因此服务层无法测"提案从哪来" | 学习链路显式入口 + `tests/helpers.seed_learning_evidence`（带使用边界文档） |

### 阶段 6.6 新发现的缺口（见 ADR-0023）

| # | 缺口 | 处理 |
|---|---|---|
| G26 | 🔴 **用户纠正永远形不成错误类别**——经验在回合收尾构建，纠正在那之后才到，`ErrorSignals.feedback_types` 那一刻恒为空。默认配置下每条经验的 `error_type` 都是 `None`，"三次同类错误生成提案"**在生产配置下不可能发生** | 新增 `experience.attributed` + `CorrectionTarget`；纠正必须**指得出被纠正的产物**（ADR-0023 §1–2） |
| G27 | 用户纠正**不指类别**——这正是阶段 6 一律归成 `UNKNOWN_ERROR` 的原因，而那个类别没有任何分辨力 | 类别按**被指产物的结构**推出（六条映射规则，逐条可指出）；指不出对象则**不归因**（ADR-0023 §2） |
| G28 | 🔴 **归因写进去了也没人再跑学习链路**——`review()` 只有 CLI 与 HTTP 两个**非自动**入口 | 提交之后同步触发；触发条件与幂等语义写入 ADR-0023 §6；黑盒 A 场景一次都不调 `/learning/runs` |

| G30 | 触发失败会把一个**已经提交**的反馈报成 500，而重试走同一条死路 | 捕获一切、完整异常只进日志、对外只给稳定错误码 + `trace_id`（ADR-0023 §7） |
